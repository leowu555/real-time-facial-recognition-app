# real-time-facial-recognition-app in C++

A real-time facial recognition application built in C++ using OpenCV. This project detects faces from images or webcam input and identifies individuals by comparing detected faces with a stored dataset.

## Features

- Real-time webcam face detection
- Face recognition using stored face data
- Image preprocessing for better recognition accuracy
- Modular C++ project structure
- CMake build system
- Expandable design for future improvements such as GUI, attendance tracking, or secure login

## Tech Stack

- C++
- OpenCV
- CMake
